# Effect sizes and power

Report an effect size for every inferential test when a defensible measure is
available.

| Analysis | Effect |
|---|---|
| Two-group mean comparison | Cohen's d or Hedges' g, with CI |
| Mann–Whitney | rank-biserial correlation |
| ANOVA | eta-squared / partial eta-squared / omega-squared |
| Correlation | r (already an effect size), with CI |
| Chi-square | Cramér's V |
| Linear regression | coefficients with CI, R² and adjusted R² |
| Logistic regression | odds ratios with CI and model performance |

Conventional small/medium/large thresholds are context aids, not clinical or
scientific importance. Interpret in domain units when possible.

## Power

- Before a study: a priori power answers required sample size for an assumed
  smallest meaningful effect.
- After a study: do not report observed post-hoc power. It is a transformation
  of the p-value. Use sensitivity analysis (detectable effect at fixed N) and
  confidence intervals instead.
- State alpha, target power, sidedness, allocation ratio, effect assumption,
  attrition inflation, and whether N is total or per group.
