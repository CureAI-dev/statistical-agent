# Reporting standards

A complete result contains:

1. analysis purpose and design
2. group/variable descriptives and analyzed N
3. assumption/diagnostic evidence and any method change
4. named test, statistic, degrees of freedom where applicable, and exact p-value
5. effect size and confidence interval where supported
6. multiplicity correction and post-hoc method
7. plain-language interpretation without causal overclaiming
8. missing-data and design limitations

Use exact p-values except `p < .001`. Do not call a non-significant result “no
effect.” Do not call an observational association causal.

Prefer a short result paragraph plus a machine-readable table. Every number in
the prose must match a value produced by a tool in the current run.
